Deploy-Automatik über GitHub aktualisieren

Die App legt für sich selbst ein Repository mit derselben Pipeline an und startet sich danach als Portainer-Stack neu. Ab dann kommt jede neue Version über eine Freigabe in GitHub – wie bei den anderen Apps.

  1. Repository mit dem laufenden Programmcode und der Pipeline anlegen, ersten Build abwarten
  2. Die laufende Version als erste Freigabe v{{ APP_VERSION }} eintragen (es ändert sich nichts am Programm)
  3. Umstieg: alte Instanz anhalten, deine Daten (Zugänge, Projekte) in den Datenordner kopieren, als Stack neu starten

Die Oberfläche ist beim Umstieg etwa eine Minute weg. Klappt der Stack nicht, startet die alte Instanz automatisch wieder. Der alte Container bleibt angehalten als „deploy-automatik-alt“ stehen, bis du ihn löschst.
